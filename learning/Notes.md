# Data Analysis with Python

MATEMATICA BASICA:

- Retorno = 1° Valor / Valor anterior - 1
- Media = soma dos retornos /numero de retornos
- Desvio = retornos - media
- soma dos quadrados = somatorio de todos os desvios ao quadrado
- volatilidade = raiz quadrada de  (soma dos quadrados / numero de retonos)

TAGS UTILIZADAS:

- round(v, x) - arredonda o dado com x casas
- i range() - i para os valores de uma lista
- Len() - conta quantidade de itens de uma lista
- sum() - soma todos os valores de uma lista
